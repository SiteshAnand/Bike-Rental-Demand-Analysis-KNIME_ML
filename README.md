🚲 Bike Rental Demand Prediction & Business Analysis

## 📌 Project Overview

Analyzed historical bike rental data to identify key demand drivers and build a predictive model using **KNIME**.

### 🎯 Objective

Predict bike rental demand (`cnt`) and generate actionable insights for fleet and operational planning.

### 🛠️ Tools Used

* **KNIME ML Analytics Platform**
* **Regression Tree**
* **GroupBy & Pivoting**
* **Data Visualization**
* **Predictive Analytics**
* **Model Evaluation**

### 📊 Model Performance

| Metric   |          Result |
| -------- | --------------: |
| **R²**   |       **87.5%** |
| **RMSE** | **63.97 bikes** |

### 🔎 Key Findings

* **Hour (`hr`)** → strongest predictor
* **Temperature (`temp`)** → major demand driver
* **Year, weekday and season** → additional important factors
* **4 PM–6 PM** → high average rental demand
* Better weather → higher demand
* Higher humidity → lower demand
* Windspeed → limited clear impact

### 💡 Business Recommendations

* Optimize bike availability during peak hours
* Use temperature and weather forecasts for demand planning
* Plan fleet allocation by weekday and season
* Use long-term demand trends for capacity planning

### 📈 Business Value

The analysis demonstrates how predictive analytics can support **fleet utilization, demand forecasting and operational decision-making**.
